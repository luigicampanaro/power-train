# Assets

## `robomimic_can.png`

One frame from the Robomimic **Can** task, taken from the public Robomimic documentation:

<https://raw.githubusercontent.com/ARISE-Initiative/robomimic/master/docs/images/can.png>

The image was cropped to remove the black border and resized to 480 x 480. It is used only by
the augmentation gallery and the tests. No dataset was downloaded.
